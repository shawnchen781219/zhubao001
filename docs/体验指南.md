# 珠宝数字化系统 — 功能体验指南

## 概述

本文档指导你如何完整体验系统的核心功能链路：

```
魔镜端（虚拟试戴） → H5端（客户查看结果） → 到店消费 → Admin端（门店管理）
```

---

## 一、快速开始

### 1.1 访问地址

**本地开发环境**:
- H5 模拟小程序：http://127.0.0.1:4202
- Admin 管理后台：http://127.0.0.1:4201

**云端部署环境**:
- H5 模拟小程序：https://你的域名/
- Admin 管理后台：https://你的域名/admin/

### 1.2 准备工作

- 确保 API 服务已启动（本地：端口3000，云端：Nginx已配置）
- 数据库已初始化并填充演示数据
- 使用现代浏览器（Chrome/Safari/Firefox）打开页面

## 二、客户体验流程（H5 端）

**场景**：客户在魔镜端完成虚拟试戴，扫码查看结果和优惠信息。

### 步骤 1：进入"试戴结果"页面

1. 打开 H5 页面（手机端访问效果最佳）
2. 页面自动加载客户最近的试戴会话
3. 页面显示：
   - 试戴状态（ANONYMOUS/QR_SHOWN/SCANNED/AUTHORIZED/COMPLETED）
   - 试戴时间
   - 试戴商品列表（商品名、价格、试戴时长）
   - 当前会话ID

**预期效果**：可以看到客户试戴了哪些商品，每件商品的价格和试戴时长。

### 步骤 2：查看"宝石护照"

1. 点击顶部 Tab 的"宝石护照"
2. 选择一个商品（如果试戴了多件）
3. 页面展示：
   - 宝石证书编号
   - 宝石类型（天然/处理）
   - 产地信息
   - 克拉数
   - 颜色等级
   - 净度等级
   - 切工质量

**预期效果**：专业的宝石鉴定信息展示，增强客户信任感。

### 步骤 3：浏览"推荐商品"

1. 点击顶部 Tab 的"推荐商品"
2. 页面展示门店所有在售商品：
   - 商品名、类型、价格
   - 商品描述
   - 标签
3. 可以对商品进行操作：
   - 收藏（心形图标）
   - 对比（勾选多个商品后点击"对比"）

**预期效果**：客户可以浏览更多商品，收藏感兴趣的款式，对比不同款式。

### 步骤 4：领取"到店消费券"

1. 点击顶部 Tab 的"到店消费券"
2. 页面展示可用优惠券模板
3. 点击"领取消费券"
4. 领取成功后显示：
   - 券码（用于到店核销）
   - 折扣信息
   - 有效期
   - 适用商品

**预期效果**：客户获得电子消费券，可在到店时使用。

### 步骤 5：预约到店时间

1. 在"到店消费券"页面下方，选择到店时间
2. 可选：今天、明天、周末下午
3. 选择后显示预约摘要

**预期效果**：客户预约到店，门店可提前准备。

### 步骤 6：联系导购

1. 页面底部显示"联系导购"区域
2. 选择咨询意向（价格、款式、定制等）
3. 填写备注
4. 点击"发送"

**预期效果**：导购在 Admin 端收到客户咨询，可主动跟进。

### 步骤 7：查看"我的消费券"

1. 页面底部 Tab 切换查看已领取的消费券
2. 显示：券码、状态、有效期

**预期效果**：客户随时查看自己的消费券。

## 三、门店管理流程（Admin 端）

**场景**：门店经理/导购在后台查看客户数据、管理试戴会话、处理消费券。

### 步骤 1：查看仪表盘

1. 打开 Admin 页面（首次加载需要1-2秒）
2. 页面自动获取认证 Token（演示模式）
3. 仪表盘显示：
   - **运营总览**：今日试戴次数、活跃客户数、优惠券数、设备在线数
   - **快捷指标卡片**：总客户、总设备、总商品、总试戴

**预期效果**：一眼掌握门店运营状况。

### 步骤 2：查看"试戴记录"

1. 点击左侧导航"🎨 试戴记录"
2. 列表显示所有试戴会话：
   - 客户姓名（或"未绑定用户"）
   - 试戴时间
   - 试戴商品数量
   - 会话状态（彩色标签）
3. 顶部筛选器可过滤：全部/进行/完成/已取消
4. 点击任一会话，右侧弹出详情面板：
   - 会话基础信息
   - 试戴商品列表（含价格、时长）
   - 关联的消费券

**预期效果**：完整追踪每个客户的试戴行为。

### 步骤 3：查看"客户管理"

1. 点击左侧导航"👤 客户管理"
2. 列表显示所有客户：
   - 姓名、电话（部分隐藏）
   - 试戴次数、消费券数
   - 最近活动时间
3. 支持搜索（姓名、电话）和筛选（全部/已跟进/未跟进）
4. 点击任一客户，右侧弹出详情面板：
   - 客户基础信息
   - 关联的试戴会话列表
   - 关联的消费券列表

**预期效果**：全面掌握客户档案，支持精准营销。

### 步骤 4：处理"设备管理"

1. 点击左侧导航"📱 设备管理"
2. 列表显示所有魔镜和平板设备：
   - 设备编码
   - 在线状态（绿色=在线，红色=离线）
   - 最后心跳时间
   - 累计试戴次数
3. 离线设备会高亮提醒

**预期效果**：监控设备运行状态，及时维护。

### 步骤 5：查看和管理"消费券"

1. 点击左侧导航"🎫 消费券"
2. 列表显示所有已发放的消费券：
   - 券码
   - 券类型
   - 客户姓名
   - 发放时间、有效期
   - 状态（已发放/已核销/已过期）
3. 顶部筛选器：全部/已发放/已核销/已过期
4. 点击任消费券，右侧弹出详情：
   - 完整券信息
   - **核销按钮**（仅对"已发放"状态显示）
5. 点击"核销"按钮 → 弹出确认对话框 → 确认后状态变更为"已核销"

**预期效果**：完整管理消费券生命周期，支持到店核销。

### 步骤 6：查看"商品目录"

1. 点击左侧导航"💎 商品目录"
2. 列表显示所有在售商品：
   - 商品名、SKU
   - 价格、类型
   - 宝石信息（如有）
3. 支持搜索

**预期效果**：掌握门店商品库存和详情。

## 四、核心链路串联演示

**场景**：完整演示客户到店 → 试戴 → 领券 → 到店消费的闭环。

### 演示脚本（建议两人配合）

**角色A（模拟客户，手机端）**:
1. 打开 H5 页面（用手机访问效果更佳）
2. 进入试戴结果页面，假装刚完成试戴
3. 浏览推荐商品，收藏2件
4. 领取消费券
5. 预约到店时间（今天）
6. 联系导购询问细节

**角色B（门店导购，电脑端）**:
1. 打开 Admin 页面
2. 在仪表盘看到今日试戴+1
3. 切换到"试戴记录"，看到新客户试戴会话
4. 切换到"客户管理"，看到新客户
5. 切换到"消费券"，看到客户领的券
6. 当客户到店时，找到该消费券，点击"核销"

**演示要点**:
- 强调客户行为和门店数据的实时联动
- 展示从"数据产生"到"数据应用"的完整链路
- 突出消费券核销的闭环验证

## 五、高级功能体验

### 5.1 商品对比（H5）

1. 在推荐商品页，勾选多个商品
2. 点击"对比"按钮
3. 底部弹出对比面板，横向展示各商品属性

### 5.2 批量操作（Admin）

1. 在客户列表，勾选多个客户
2. 出现批量操作按钮："批量跟进"/"批量标记VIP"
3. 批量操作后刷新列表

### 5.3 数据导出（Admin）

1. 在任意列表页（如消费券列表）
2. 点击右上角"导出Excel"按钮
3. 下载当前筛选条件下的数据

### 5.4 搜索和筛选（Admin）

- 客户列表：支持按姓名、电话搜索
- 试戴记录：支持按客户、状态筛选
- 消费券：支持按状态、时间范围筛选

## 七、常见问题

### Q: H5 页面显示"网络错误"
**A**: API 服务未启动。本地开发环境检查端口3000，云端检查 Nginx 代理配置。

### Q: Admin 页面加载后没有数据
**A**: 数据库未初始化。运行迁移和种子数据：
```bash
pnpm run db:migrate
pnpm run db:seed
```

### Q: 消费券核销失败
**A**: 检查消费券状态是否为"已发放"，已核销或已过期的券无法再次核销。

### Q: 客户端看不到试戴数据
**A**: 确保至少有一次试戴会话数据。如没有，运行种子数据重新生成。
