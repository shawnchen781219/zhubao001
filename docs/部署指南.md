# 珠宝店数字化系统 — 云端部署指南

## 一、部署架构概览

```
用户手机浏览器/微信
       ↓ HTTPS
   Nginx 反向代理 (443)
       ├── /api/*      → API 服务 (127.0.0.1:3000)
       ├── /admin/*    → Admin 静态文件
       └── /           → H5 静态文件
```

## 二、服务器环境准备

### 2.1 服务器要求

- **系统**: Ubuntu 22.04 LTS 或更高
- **配置**: 最低 2C4G（推荐 4C8G）
- **磁盘**: 20GB+（数据库会增长）
- **网络**: 开放 80/443 端口
- **域名**: 已备案域名（用于 HTTPS）

### 2.2 安装基础软件

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Node.js 22.x
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 pnpm
corepack enable
corepack prepare pnpm@10.34.1 --activate

# 安装 PostgreSQL 16
sudo apt install -y postgresql-16

# 安装 Nginx
sudo apt install -y nginx

# 安装 PM2（进程守护）
sudo npm install -g pm2

# 安装 certbot（SSL 证书）
sudo apt install -y certbot python3-certbot-nginx
```

### 2.3 配置 PostgreSQL

```bash
# 切换到 postgres 用户
sudo -u postgres bash

# 创建数据库和用户
psql <<EOF
CREATE ROLE jewelry WITH LOGIN PASSWORD '你的强密码';
CREATE DATABASE jewelry_digital OWNER jewelry;
GRANT ALL PRIVILEGES ON DATABASE jewelry_digital TO jewelry;
EOF

# 修改 pg_hba.conf 允许本地连接
# 在 /etc/postgresql/16/main/pg_hba.conf 中添加：
# local   jewelry_digital   jewelry   md5
# host    jewelry_digital   jewelry   127.0.0.1/32   md5

sudo systemctl restart postgresql
```

## 三、部署步骤

### 3.1 上传代码

```bash
# 在服务器上创建部署目录
mkdir -p /var/www/jewelry
cd /var/www/jewelry

# 方式一：Git 克隆（推荐）
git clone <你的仓库地址> .

# 方式二：SCP 上传
# 在本地执行：
# scp -r jewelry-digital-system/* user@server:/var/www/jewelry/
```

### 3.2 安装依赖与初始化

```bash
cd /var/www/jewelry

# 安装依赖
pnpm install

# 编译 shared 包
pnpm --filter @jewelry/shared build

# 编译 API
DATABASE_URL="postgresql://jewelry:你的强密码@localhost:5432/jewelry_digital?schema=public" \
  pnpm --filter @jewelry/api build

# 运行数据库迁移
DATABASE_URL="postgresql://jewelry:你的强密码@localhost:5432/jewelry_digital?schema=public" \
  npx prisma migrate deploy --schema prisma/schema.prisma

# 生成 Prisma Client
DATABASE_URL="postgresql://jewelry:你的强密码@localhost:5432/jewelry_digital?schema=public" \
  npx prisma generate --schema prisma/schema.prisma

# 填充演示数据
DATABASE_URL="postgresql://jewelry:你的强密码@localhost:5432/jewelry_digital?schema=public" \
  npx tsx apps/api/scripts/seed/seed-demo.ts
```

### 3.3 修改前端 API 地址

**重要**：部署前需要把前端的 API 地址从 `http://127.0.0.1:3000` 改为你的域名：

```bash
# admin/app.js
sed -i 's|http://127.0.0.1:3000|https://你的域名/api|g' apps/admin/public/app.js

# h5/app.js
sed -i 's|http://127.0.0.1:3000|https://你的域名/api|g' apps/h5/public/app.js
```

### 3.4 使用 PM2 启动 API 服务

```bash
# 创建 PM2 配置文件
cat > ecosystem.config.cjs <<'EOF'
module.exports = {
  apps: [{
    name: 'jewelry-api',
    script: 'apps/api/dist/main.js',
    cwd: '/var/www/jewelry',
    instances: 2,
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production',
      DATABASE_URL: 'postgresql://jewelry:你的强密码@localhost:5432/jewelry_digital?schema=public',
      JWT_SECRET: '你的JWT密钥_请随机生成至少32位',
      APP_PORT: 3000,
    },
  }],
};
EOF

# 启动
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup  # 设置开机自启
```

### 3.5 配置 Nginx

```bash
cat > /etc/nginx/sites-available/jewelry <<'EOF'
server {
    listen 80;
    server_name 你的域名;

    # 强制 HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name 你的域名;

    # SSL 证书（certbot 会自动填充）
    ssl_certificate /etc/letsencrypt/live/你的域名/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/你的域名/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Admin 后台（静态文件）
    location /admin/ {
        alias /var/www/jewelry/apps/admin/public/;
        index index.html;
        try_files $uri $uri/ /admin/index.html;
    }

    # H5 前端（默认页面）
    location / {
        root /var/www/jewelry/apps/h5/public;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(css|js|jpg|jpeg|png|gif|ico|svg|woff2)$ {
        root /var/www/jewelry/apps/h5/public;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}
EOF

# 启用站点
sudo ln -sf /etc/nginx/sites-available/jewelry /etc/nginx/sites-enabled/
sudo nginx -t          # 测试配置
sudo systemctl reload nginx

# 申请 SSL 证书
sudo certbot --nginx -d 你的域名
```

### 3.6 验证部署

## 五、常见问题

### Q: 前端页面空白或 CORS 错误
**A**: 检查前端代码中的 `API_BASE` 是否已改为 `https://域名/api`，同时 Nginx 是否正确代理了 `/api/` 路径。

### Q: API 返回 500 错误
**A**: 检查 PostgreSQL 是否在运行，`pm2 logs jewelry-api` 查看错误日志。

### Q: 手机端 HTTPS 证书错误
**A**: 确保 certbot 已成功签发证书，且域名已正确解析到服务器 IP。

### Q: PM2 重启后数据库连接失败
**A**: 检查 `ecosystem.config.cjs` 中的 `DATABASE_URL` 是否正确，PostgreSQL 是否在运行。
