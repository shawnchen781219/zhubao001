# 珠宝店数字化系统 — 云端部署清单

> **目标**：让客户用手机浏览器直接访问 H5，同时用电脑访问 Admin 管理后台。

---

## 一、架构总览

```
用户手机/电脑
     ↓ HTTPS (443)
   Nginx
     ├── /          → H5 静态页面（手机访问入口）
     ├── /admin/    → Admin 静态页面（管理后台入口）
     └── /api/      → NestJS API 服务（内部 :3000）
                        │
                        ↓
                     PostgreSQL 16
                   (127.0.0.1:5432)
```

| 组件 | 技术栈 | 端口 | 说明 |
|---|---|---|---|
| H5 前端 | 原生 HTML/JS/CSS + Google Fonts | 4202 | 模拟小程序 |
| Admin 后台 | 原生 HTML/JS/CSS + Inter + Noto Serif SC | 4201 | 管理面板 |
| API 服务 | NestJS 11 + Prisma 7 + @prisma/adapter-pg | 3000 | HTTP API |
| 数据库 | PostgreSQL 16 | 5432 | 持久化 |
| 进程守护 | PM2 | - | Node 进程管理 |
| 反向代理 | Nginx | 80/443 | HTTPS + 静态文件 |

## 四、服务器部署步骤

### Step 1：服务器初始化

```bash
# 1. 更新系统
sudo apt update && sudo apt upgrade -y

# 2. 安装 Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# 3. 安装 pnpm
corepack enable
corepack prepare pnpm@10.34.1 --activate

# 4. 安装 PostgreSQL 16
sudo apt install -y postgresql-16

# 5. 安装 Git / Nginx / PM2
sudo apt install -y git nginx
sudo npm install -g pm2
pm2 startup    # 开机自启
```

### Step 2：初始化数据库

```bash
# 切换到 postgres 用户，创建数据库
sudo -u postgres psql <<EOF
CREATE ROLE jewelry WITH LOGIN PASSWORD '替换为强密码（至少16位）';
CREATE DATABASE jewelry_digital OWNER jewelry;
GRANT ALL PRIVILEGES ON DATABASE jewelry_digital TO jewelry;
\c jewelry_digital
GRANT ALL ON SCHEMA public TO jewelry;
EOF

# 允许本地连接（编辑 /etc/postgresql/16/main/pg_hba.conf）
# 在文件末尾添加：
# local   all   jewelry   md5
# host    all   jewelry   127.0.0.1/32   md5

sudo systemctl restart postgresql
```

**验证数据库**：
```bash
psql -U jewelry -d jewelry_digital -h 127.0.0.1 -c 'SELECT 1;'
```

### Step 3：部署代码

```bash
# 创建部署目录
sudo mkdir -p /var/www/jewelry
sudo chown $USER:$USER /var/www/jewelry
cd /var/www/jewelry

# 克隆代码
git clone https://你的仓库地址.git .

# 安装依赖
pnpm install

# 构建 shared 包（必须先构建，其他包依赖它）
pnpm --filter @jewelry/shared build

# 生成 Prisma Client
DATABASE_URL="postgresql://jewelry:替换为强密码@127.0.0.1:5432/jewelry_digital?schema=public" \
  npx prisma generate --schema prisma/schema.prisma

# 运行数据库迁移
DATABASE_URL="postgresql://jewelry:替换为强密码@127.0.0.1:5432/jewelry_digital?schema=public" \
  pnpm --filter @jewelry/api exec -- prisma migrate deploy

# 填充演示数据（可选，演示前建议执行）
DATABASE_URL="postgresql://jewelry:替换为强密码@127.0.0.1:5432/jewelry_digital?schema=public" \
  pnpm --filter @jewelry/api exec -- tsx scripts/seed/seed-demo.ts

# 构建 API
pnpm --filter @jewelry/api build
```

### Step 4：配置 PM2 启动服务

创建 `ecosystem.config.cjs` 文件：

```javascript
// /var/www/jewelry/ecosystem.config.cjs
module.exports = {
  apps: [
    {
      name: "jewelry-api",
      script: "./dist/main.js",
      cwd: "/var/www/jewelry/apps/api",
      instances: 1,
      autorestart: true,
      env: {
        NODE_ENV: "production",
        DATABASE_URL: "postgresql://jewelry:替换为强密码@127.0.0.1:5432/jewelry_digital?schema=public",
        APP_PORT: 3000,
      },
    },
    {
      name: "jewelry-admin",
      script: "./scripts/serve.mjs",
      cwd: "/var/www/jewelry/apps/admin",
      instances: 1,
      autorestart: true,
      env: { NODE_ENV: "production" },
    },
    {
      name: "jewelry-h5",
      script: "./scripts/serve.mjs",
      cwd: "/var/www/jewelry/apps/h5",
      instances: 1,
      autorestart: true,
      env: { NODE_ENV: "production" },
    },
  ],
};
```

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 list    # 确认三个服务都 online
```

### Step 5：配置 Nginx 反向代理 + HTTPS

#### 5.1 创建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/jewelry
```

```nginx
# 强制 HTTPS
server {
    listen 80;
    server_name 你的域名.com;
    return 301 https://$host$request_uri;
}

# HTTPS 主配置
server {
    listen 443 ssl http2;
    server_name 你的域名.com;

    # SSL 证书（Certbot 会自动填充路径）
    ssl_certificate /etc/letsencrypt/live/你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/你的域名.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # Gzip 压缩（提升静态页面加载速度）
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
    gzip_min_length 1000;

    # 安全头
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;

    # H5 静态文件（默认首页）
    location / {
        root /var/www/jewelry/apps/h5/public;
        index index.html;
        try_files $uri $uri/ /index.html;

        # 浏览器缓存 1 天
        location ~* \.(css|js|jpg|jpeg|png|gif|ico|svg|woff2)$ {
            expires 1d;
            add_header Cache-Control "public, immutable";
        }
    }

    # Admin 静态文件
    location /admin {
        alias /var/www/jewelry/apps/admin/public;
        index index.html;
        try_files $uri $uri/ /admin/index.html;

        location ~* \.(css|js|jpg|jpeg|png|gif|ico|svg|woff2)$ {
            expires 1d;
            add_header Cache-Control "public, immutable";
        }
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
    }

    # 静态资源专用代理（提升 API 请求性能）
    client_max_body_size 32M;
}
```

#### 5.2 启用配置

```bash
# 启用站点
sudo ln -sf /etc/nginx/sites-available/jewelry /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default

# 测试配置
sudo nginx -t

# 重载
sudo systemctl reload nginx
sudo systemctl enable nginx
```

#### 5.3 申请 SSL 证书（Let's Encrypt）

```bash
# 先确保域名已解析到服务器 IP
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名.com

# 自动续期
sudo certbot renew --dry-run
```

### Step 6：更新前端代码中的 API 地址

**重要！** 默认代码写死了 `http://127.0.0.1:3000`，部署前必须改成生产环境地址。

编辑文件 `apps/admin/public/app.js` 和 `apps/h5/public/app.js`：

```javascript
// 替换这一行：
const API_BASE = "http://127.0.0.1:3000";

// 改为（动态检测，本地开发/生产自动切换）：
const API_BASE = window.location.hostname === "localhost" ||
                 window.location.hostname === "127.0.0.1"
    ? "http://127.0.0.1:3000"
    : window.location.origin + "/api";
```

**更新完记得重启前端**：
```bash
pm2 restart jewelry-admin jewelry-h5
```

### Step 7：配置防火墙

```bash
# 启用 ufw
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw enable
sudo ufw status
```

> ⚠️ **不要** 对外开放 3000、4201、4202、5432 端口，所有外部请求都应走 Nginx 443。

## 七、常见问题排查

### Q1：手机访问 H5 页面空白 / API 报错？
- **检查** `apps/h5/public/app.js` 中的 `API_BASE` 是否已改为生产环境地址
- **检查** Nginx 配置中 `location /api/` 是否正确代理

### Q2：Admin 后台显示 "认证失败"？
- **原因**：Token 生成时 API 地址不对
- **检查**：`curl https://域名/api/auth/staff/demo-token`

### Q3：Google Fonts 加载慢（国内）？
- **解决**：替换为国内 CDN 镜像
  ```html
  <link href="https://fonts.loli.net/css2?family=Noto+Serif+SC:wght@400;600;700;900&display=swap" rel="stylesheet" />
  ```
- 或使用系统字体 `font-family: "Noto Serif SC", "Source Han Serif SC", serif;` 配合本地字体包

### Q4：PM2 进程意外退出？
```bash
pm2 logs  # 查看具体错误
pm2 status  # 查看重启次数
```

### Q5：Nginx 502 Bad Gateway？
- **原因**：API 服务未启动
- **解决**：`pm2 restart jewelry-api`

### Q6：PostgreSQL 连接失败？
```bash
# 检查服务状态
sudo systemctl status postgresql

# 检查密码是否正确
psql "postgresql://jewelry:密码@127.0.0.1:5432/jewelry_digital"
```

## 八、性能优化建议

| 优化项 | 实施 |
|---|---|
| **静态资源 CDN** | 将 `apps/h5/public` 和 `apps/admin/public` 上传到 CDN |
| **开启 HTTP/2** | Nginx 1.9.5+ 默认支持 |
| **API 响应缓存** | 在 API 端添加 ETag / Cache-Control |
| **PM2 集群模式** | 改 `instances: 1` 为 `instances: 2`（需要 4C 以上） |
| **PostgreSQL 连接池** | 调整 `pg.Pool` 默认值（生产建议 20 个连接） |
| **图片优化** | 产品图片用 WebP 格式，体积减小 30% |

## 九、安全加固

- [ ] SSH 禁用 root 登录 + 改用密钥认证
- [ ] PostgreSQL 密码足够复杂（至少 16 位）
- [ ] Nginx 隐藏版本号：`server_tokens off;`
- [ ] API 端添加限流：使用 `@nestjs/throttler` 限制每个 IP 60 次/分钟
- [ ] 定期备份数据库：
  ```bash
  pg_dump -U jewelry -d jewelry_digital -h 127.0.0.1 > backup_$(date +%Y%m%d).sql
  ```
